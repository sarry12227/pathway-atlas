# 逐题引导的内部题库

本文件只供 Agent 查阅。按 SKILL.md 的逐题循环取当前一题及其选项，不将本文件作为整份问卷展示给用户。原有 1–20 是信息主题编号，含多个字段的主题分轮完成。

选择题逐项列出带字母的选项，并说明单选或多选；所有选项只属于当前问题。自由文本题提供一种回答格式或例子即可，不把例子当成答案。遇到用户不了解的术语，先简短解释当前项，再等用户选择。

## 信息主题

1. **性别** 选项：男 / 女 / 不便回答。
2. **高考报名省份** 填写参加高考报名的省份；不要填写详细住址。
3. **当前城市与所在高中** 先问当前城市，回答后再问所在高中完整校名；不要填写班级编号。
4. **年级与预计高考年份** 选项：高一 / 高二 / 高三；年级回答后，下一轮确认预计高考年份。
5. **班型/培养层次** 填写班型/培养层次，如普通班、重点班、竞赛班；不填写具体班级编号。
6. **选科组合** 按“物理+化学+生物”等格式填写，回答后再确认分数采用原始分还是赋分。
7. **最近一次大考总分** 先问本人总分，再逐轮补齐考试名称、日期、考试范围、满分；每轮只问一个尚缺字段。
8. **最近一次大考校排名（年级排名）** 先问排名，再逐轮补齐排名口径、同口径参考人数；随后询问是否另有省级或大型联考位次，有则逐项补齐。
9. **过往最高与正常水平校排** 分轮询问过往最高名次、对应考试、通常发挥时的名次区间；不知道可明确填写不知道。
10. **获奖经历** 填写学科竞赛、科创比赛、英语比赛、作文比赛等；没有请填“无”。
11. **特殊活动经历** 填写研学、夏令营、社会实践、志愿者等；没有请填“无”。
12. **理想大学** 写出一至五所理想大学；没有明确目标可填“不确定”。
13. **为什么想去这些学校** 可多选：名气大 / 排名高；专业实力强；城市好 / 地理位置优越；家里有人读过 / 熟人推荐；分数线刚好合适；听老师 / 同学说的；其他。
14. **想学什么专业（大类）** 可多选：计算机 / 软件 / 人工智能；电子信息 / 通信工程；电气工程 / 自动化；机械工程 / 航空航天；能源动力 / 材料科学；土木工程 / 建筑学；数学 / 物理 / 化学 / 生物（基础科学）；临床医学 / 口腔医学；药学 / 护理学；法学；财会 / 金融 / 经济学；汉语言文学 / 新闻传播 / 历史 / 哲学；外语（英语 / 小语种）；管理类（工商管理 / 人力资源等）；教育 / 心理学；其他。
15. **为什么想学这个专业** 可多选：自己感兴趣 / 热爱这个领域；好就业 / 薪资高；家人建议 / 家族从事相关行业；听说前景好 / 风口行业；老师推荐；同学都选这个；其他。
16. **想去哪个城市或地区读大学** 可多选：北京 / 上海 / 广州 / 深圳 / 武汉 / 杭州 / 南京 / 苏州 / 成都 / 重庆 / 西安；其他一线城市；其他省会城市；无所谓，学校好就行；选好意向地区后，下一轮询问不能接受的地区。
17. **对大学毕业后的想象** 可多选：直接工作，积累职场经验；考研 / 保研，继续深造；考公务员 / 事业编，求稳定；出国留学，开阔视野；创业，做自己的事业；还没想好，走一步看一步；其他。
18. **目前最焦虑或最担心** 可多选：孩子成绩不稳定，怕高考发挥失常；不知道孩子适合学什么专业，怕选错路；怕分数够了但选错学校 / 专业；不知道除了裸分高考，还有哪些升学途径；孩子没有获奖经历，担心影响强基计划 / 综合评价；孩子学习动力不足，需要外部激励和引导；对志愿填报规则完全不了解，怕踩坑；家庭有特殊情况（经济、身体、户籍等），不知道有哪些政策可以利用；其他。
19. **最希望规划方案解决什么问题** 用一至三句话填写期望得到的具体帮助。
20. **规划条件、限制与特殊升学方向** 按下方条件清单逐项询问；每轮只处理当前一项，得到用户回答后再进入下一项。

## 第 20 题：内部条件清单

以下是 Agent 的覆盖清单，不是发给用户填写的表格。标题可用“规划条件 · 学费预算”等当前主题，不必反复显示冗长编号。每个分号分隔的事项都单独处理；用户已明确回答的事项直接记入。询问某路径前用一句话解释名称，询问是否考虑与是否符合资格是两个不同问题。资格不明记录待核验，不要求家庭自行判定，也不在画像确认前作政策判断。

- 国家专项资格；地方专项资格；高校专项资格。选项：已了解且认为符合 / 认为不符合 / 不确定，之后请帮我核验。
- 是否考虑强基计划；是否考虑综合评价。选项：考虑 / 不考虑 / 不了解，之后请帮我判断。
- 是否考虑公费师范；优师计划；定向医学生。逐项选：考虑 / 不考虑 / 不确定。
- 是否考虑军队；公安；司法；消防；航海。逐项选：考虑 / 不考虑 / 不确定。
- 是否考虑港澳高校；中外合作；境外升学。逐项选：考虑 / 不考虑 / 不确定。
- 艺术经历或方向；体育经历或方向；竞赛或学科特长。逐项选：有（再问具体情况） / 无 / 不确定。
- 户籍省市；学籍省市；城乡属性。只问大致范围，可回答不知道或不便回答。
- 外语语种；外语大致水平。分别询问，不据此自动推断面试或科研能力。
- 已知体检限制；视力限制；色觉限制；政审相关限制；体能限制。逐项选：有已知限制（可简述） / 无已知限制 / 不确定 / 不便回答。不询问病历，也不把“无已知限制”当成已通过体检或政审。
- 是否接受服务期；定向就业；地域约束。逐项选：接受 / 不接受 / 了解具体条件后再决定。
- 可承受的学费；生活费预算。分别询问金额；下一轮补齐未说明的每年或总预算口径。
- 是否接受民办；中外合作；高收费专业。逐项选：接受 / 不接受 / 看费用和项目再决定。已明确回答中外合作的，保留原答，仅有条件缺口时追问。
- 学校与专业的优先顺序。单选：学校优先 / 专业优先 / 两者平衡 / 不确定。
- 是否接受专业调剂。单选：接受 / 不接受 / 了解规则后再决定。
- 冲稳保风险偏好。单选：偏冲刺 / 均衡 / 偏稳妥 / 不确定；也可自行描述。

每项都允许明确的“不知道 / 不确定 / 不便回答 / 不适用”。回答未到来时保持未询问；不能为了填满内部字段而替用户选择这些状态。
