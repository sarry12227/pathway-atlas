# 逐题引导的内部题库

新咨询直接问“孩子在哪个省份参加高考？”。已有答案先回填，再问当前一道主题题；只显示这一题及其选项。以下目录和内部字段不展示给家长。安装、加载和必要准备遵循 SKILL.md 的静默准备规则。

## 收敛规则

原1—20是信息主题编号，72个子项是内部存储字段。**每个字段不必单独问一遍。** 默认按下表24道主题题推进，已答内容跳过；同一主题最多一次补问，全程最多六次补问，之后汇总确认一次。不能三轮就跳过家庭条件，也不能为了补齐字段无限追问。

一次只处理一个相关主题。如“8月校内期末考，550/750分”同时回答考试、时间、范围、得分和满分；“近视250度，其余无已知限制”同时覆盖本题列明的体检情况。不再拆开确认。用户主动提供其他主题信息时一起记录，轮到该主题直接复用。

优先补问会改变规划的缺口：高考省份/年份、完整选科、成绩与排名口径、专业方向、外语和预算单位。原因、最好排名对应考试等辅助细节缺失不阻塞。用完当前题或总额度后，保存“本轮待核验”，继续；这不表示家长说了“不知道”，也不表示条件满足或不考虑路径。

明确“不知道/跳过”只覆盖刚问的主题；“其他不清楚”只覆盖当前列出的事项。选择题每项独立一行，说明单选或多选，保留自由补充入口。控件容量不足时用字母选项。路径兴趣用一道多选题，先简释名称；是否愿意了解与是否具备资格分开。未选项只表示本轮不主动展开，不作永久拒绝或资格判断。

## 私有进度与确认

新会话用 schema_version `1.1`：

```json
{"schema_version":"1.1","responses":{},"question_history":[]}
```

每次运行 `python -m scripts.intake_progress --state <private>/intake.json`，取 `question_id`、`question_fields`、`next_question`。问过并收到回复后，把当前题号、完整用户原话和明确覆盖字段写入私有 `reply.json`：

```json
{"question_id":"province","quote":"湖北，高三，2027年高考","responses":{"province":{"status":"answered","quote":"湖北"},"grade":{"status":"answered","quote":"高三"},"exam_year":{"status":"answered","quote":"2027年高考"}}}
```

运行 `python -m scripts.intake_progress --state <private>/intake.json --record <private>/reply.json` 保存并取下一题。可记录本轮主动提供的其他主题，但引文必须来自该回复。字母选择引用真实字母，结合当时选项把含义记入画像；不拿助手提问冒充用户原话。一次回复只记录一次；工具结果不明时先读取已有进度，不重复提交。

字段状态为 `answered`、`unknown`、`skipped`。程序另列 `deferred_fields`，不伪造答案；确认画像时披露实际缺口，例如“××暂未明确，本轮按条件建议处理”。未问主题仍在 `missing_fields`，不会因为补问额度用完而跳过。

只有含义足够明确的字段才写入 `responses`。例如只说一个金额、尚不清楚是每年还是总额，先把原话留在本轮 `quote`，不要提前把预算字段标为已答；本题一次补问确认单位。无法读取的划线图片同理，记录收到图片的真实回复，在补问中转文字；未知或补问耗尽则按现有线索继续。

`collecting`继续当前题；`confirming`展示匿名画像；收到真正确认后保存：

```json
"confirmation":{"profile_digest":"当前画像digest","progress_digest":"当前进度digest","quote":"用户实际确认原话"}
```

带 `--profile-digest <当前画像digest>` 检查，`ready_for_planning=true` 后规划。程序校验覆盖与确认一致性，不证明Agent理解必然正确。归一化v3时缺失项用未知值，私有进度保留原因；缺省份等计算必需项则该部分不可算，不能创造数据。

已有 `1.0` 完整确认记录继续有效；正在收集的旧记录保留全部 `responses`，用 `--record` 迁移。历史补问次数从真实问答恢复，不能借升级重置额度。已初始化会话直接续用，不因更新重新问卷。只有事实变化才确认受影响部分，格式修复不重复确认。

## 避免误读与循环

- “约四五百人”保留约400—500，不能摘要成确定500。整数接口填空，范围留在私有记录；模型使用单值时标为计算假设，不作为家长事实。
- “年级中等”不变成年级50%；用具体校排或划线，不追索精确人数。
- 已说近视250度时复用视力字段，只问其他尚缺且影响判断的限制。
- 排除地区与例外一起保留，不删掉允许的城市或学校。
- 愿意了解某路径与不接受其约束可并存。额度内解释一次常见约束并澄清取舍；没有新回复就作为条件候选，不写成完全匹配。
- 专项不了解由Agent查。城乡属性、城市或高中名本身不构成三类专项资格结论。
- 确认用“以上是否准确：A准确开始，B有修改”。上一句若明确问“有修改吗”，回答“没有”才表示没有修改；避免双重问句误读。
- 主题已覆盖且用户催交付，立即确认或沿用确认并交付，不因辅助细节重启问卷。

## 年级与高考年份

以本轮真实北京时间为准，**每年7月1日切换下一届**。当前年为Y：1—6月高三/高二/高一对应Y/Y+1/Y+2；7—12月对应Y+1/Y+2/Y+3。跨元旦不额外换届。

有执行能力时用 `python -m scripts.questionnaire_intake --grade-options`，可靠宿主日期可传 `--as-of YYYY-MM-DD`，不使用示例或考试日期。主题题也按同一规则生成选项。无执行能力时依据可靠日期计算；日期不可得时问不带年份的年级，再补问预计年份。

选择带年份的选项后一起记录，不再确认年份；只说年级可在本题唯一补问中确认推算年。明确年份优先，复读/已考/“刚读完”冲突才澄清。旧画像年份不因跨7月1日自动改写。7月1日是年级口径，不表示当届填报、录取或补录已结束。
