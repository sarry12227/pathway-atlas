# 用高考喜报估算校排对应省排

这是默认快速规划的主要校准路线。喜报经常来自第三方、自媒体、抖音和家长分享，不能要求只有考试院来源才可用。**可读的一份材料就能支持注明出处和假设的粗估**；多份材料用于比较年份、口径和波动，不是必须达到某个来源数量才允许计算。

## 搜什么、读什么

按完整高中名＋省市＋年份检索近三年，轮换“高考喜报／高考成绩／600分以上／一本人数／特控线上线率／985人数／211人数”。同名歧义时补“中学／高中／所在城市”。先读学校或教育部门发布，再读可访问的当地媒体、教育机构文章、抖音公开分享；不能在搜索到第三方后立即停下等官方。浏览器失效就用当前可读正文的工具；图片看原图，视频读可见文字、字幕或实际转写。保存最小相关摘录、链接、发布者、适用年份、文理/物理/历史口径。标题和搜索词命中不等于读到了数字。

找不到本校有效人数信息时，在首轮预算内依次用本校往年、同城同档学校代理。代理要说明学校层次、招生范围、学生群体为什么可比；有历届人数时按本届校排百分比对齐。不要把一个栏目没有结果说成“全网不存在”“只能学校内部提供”。检索不到只记录本轮范围与缺口，自动继续规划。

## 喜报不必自带校排—省排对应表

| 可读材料 | 转换方式 |
| --- | --- |
| 600分及以上120人、560分及以上240人 | 同年同组一分一段表给出600分、560分的累计省位；形成校位约120、240的两个边界，再对当前校位插值 |
| 600分以上占24%，该届同组500人 | 500×24%=120人，再走分数段人数路线；没有同口径总人数时保留比例信息，继续找人数 |
| 985层次80人、211层次200人、本科上线人数 | 用本省同组对应代表校的已读历史门槛作层次位次参照；说明是层次代理，不能把985/211当作全省统一官方分数线。实际录取人数也不等于纯成绩名次，可能混有特殊路径，需要较宽浮动 |
| 一本/特控线人数 | 优先取得该年度该类控制分数，再结合对应一分一段表转换；不能把旧一本、特控、实际一本录取三种定义混为同一口径 |
| 只有一个非榜首累计人数锚点 | 在当前校位距该锚点0.5–2倍内，可按校位比例给较宽粗估，至少±50%规划浮动；写清是模型假设，不是观察到的完整分布 |
| 两个以上锚点但当前校位稍超范围 | 相邻锚点有限外推，仅在距最近锚点0.5–2倍内，至少±40%浮动；太远则继续代理/目标梯度 |
| 只有最高分或状元 | 只能表明该届顶端水平；不能凭它为第200名编造分布。继续人数/比例/层次与同档学校检索，预算到时仍完成七部分正文 |

累计人数属于分布边界。并列同分、届间生源差异及喜报宣传口径造成误差，正文用“约”与区间。不同转述冲突时保留独立情景，参考中心用最新年份情景的中位数、区间覆盖各情景，不能把转述平均成“已核实事实”。重复搬运不要伪装为独立确认。

## 内部输入：school_report

保留 `brief` 的原有字段、`sources`、`score_table`、候选和行动；把 `calibration` 改为以下结构。全部由Agent准备，用户不写JSON。

```json
{
  "method": "school_report",
  "basis": "喜报累计人数形成校位边界，结合一分一段作参考",
  "reports": [{
    "school": "已确认的高中名称",
    "year": 2025,
    "subject_group": "物理",
    "comparability": "same_school",
    "cohort_size": 500,
    "source_kind": "social_video",
    "citation": {"source_id": "report1", "quote": "实际读到且包含校名和同口径500人的原句"},
    "metrics": [
      {"kind": "score_count", "score": 600, "count": 120,
       "citation": {"source_id": "report1", "quote": "实际读到的600分及以上120人原句"}},
      {"kind": "score_count", "score": 560, "count": 240,
       "citation": {"source_id": "report1", "quote": "实际读到的560分及以上240人原句"}}
    ]
  }]
}
```

这是结构说明，示例数字不能冒充真实材料。3+3的 `subject_group` 填 `综合`，3+1+2填实际首选科目。旧理科与新物理类、全校与重点班、全体与某一选科组不能无声混算；若用户的排名是全校混排，先用可比全校出口或有依据的分组转换，不能擅自认成物理类位次。`cohort_size` 缺失可为null，暂按同规模假设并加宽范围。`regional_comparable` 代理另填 `comparability_reason`。

`source_kind`：`school_publication / third_party / social_video / user_material`，描述材料起源，不是强制信任等级。公开来源的标题/正文均保留；引用里的数值必须在保存原文中可定位。截图或视频应保存实际视觉/OCR/转写结果及原始出处；不能用未看过的画面编引用。

原文用学校简称时，`school`仍填画像确认的全称，`reported_school`填原文实际名称，`school_identity_basis`说明已核对同省同市与全称/简称对应；引用检查绑定原文简称，不强迫原文凭空出现全称。不得把同名但不同地区学校当作本校。

`score_rate`：将 `count` 换成 `rate_percent`（24表示24%）。`tier_count/tier_rate`：将 `score` 换成原文 `label`，增加 `benchmark: {year, basis, ranks: [{province_rank, citation}, ...]}`。位次参照可以是一所或多所真实代表校的门槛，原文引用绑定具体位次，`basis` 说明选择理由和局限。查到的是录取分数时先通过同年表得到位次，在输入中保留支持该位次的表行；不要要求原投档表自己带位次列。

`score_table` 是本次最终报告的参照表；若喜报年份更早，在 `historical_score_tables` 放各喜报同年同组选表，结构与 `score_table` 一致，每年只放一份。同一喜报各分数必须有实际表行，不把缺失单元格补成精确值。默认回查当前年到前三年，制度变化不硬凑同口径。

一分一段表允许“当分人数为零”带来的重复累计位次和顶部累计零。保留原始行即可；程序按分数递减、累计人数不下降校验，不要求手工删掉这些合法分段。

## 必须走到交付

来源采用、换搜索词、换工具、使用往年和明确标注的代理，均是Agent自己的工作，不发“选1继续／选2提供校排数据／选3以后再跑”。画像已确认就执行一次 `brief`，拿到 `report_generated=true` 和非空 `report_text` 才能说程序生成了报告，然后把七部分正文直接发给用户。`start`、预检、测试通过、下载Excel或保存session均不代表 `brief` 已执行。

原始联考/月考分数只显示为本次成绩；不能用它直接筛选投档表再写“560分能上这些校”或“够不到目标校”。个人冲稳保使用喜报估算位次；还没有校准时用真实学校门槛给目标梯度，禁止把原始校考分数当成可及线或Excel高亮筛选线。
