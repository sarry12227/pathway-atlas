# 研究失败时的继续与交付

画像确认后，在能力预检、网页打不开、附件提取失败、研究任务积压或无证据交付时读取本指南。仍使用同一 [host workflow](host-workflow.md)、[检索流程](retrieval-playbook.md) 和[信源规范](source-policy.md)；不替换画像、不手工制造证据。

## 先验证具体能力

`preflight` 只检查宿主声明及可选模块是否可发现。`standard` 不保证某个网站可用，`pdfplumber` 缺失也不表示所有网页、PDF或政策不可读。宿主在私有工作区记录实际工具、目标、一次调用结果和失败分支；确认后的首次研究先尝试一个原始正文或附件，具备搜索工具时再验证一次检索。

- `browse` 指能打开并读到公开原文的能力，包括宿主网页阅读器、HTTP读取器及浏览器；不是 Chrome 的别名。
- `search` 使用当前确实可用的检索能力。没有 Exa、mcporter 或 Jina 配置，不代表没有宿主搜索或官方公开导航入口。不能为凑能力标志而声称工具可用。
- 只有 `browse` 时仍可从受信省份目录、已知官方链接及原页公开导航读取资料，预检为 `standard`，披露搜索覆盖受限。只有搜索摘要而不能打开原文时，不能认定政策或数字已核验。
- 明确进入 `offline` 后不偷偷联网。若所有读取方式均失效，保留已认证材料，并按下文生成准备版；有权限且环境确实恢复时再重新确认能力与会话状态。

## 按失败分支换路线

| 失败点 | 继续方式 | 该分支何时结束 |
| --- | --- | --- |
| 浏览器崩溃或调试器未连接 | 用现有宿主网页阅读器；或从受信目录经安全下载器读取公开HTML/附件 | 替代读取也实测失败，才记录受影响任务不可用 |
| 首页空白、动画、JS壳 | 查正文详情页、官方导航、HTML里的附件/图片链接；打开高校官网发布的对应简章 | 某一首页不能代表整个域名、所有年度或所有高校均不可用 |
| PDF解析库缺失 | 用现有PDF适配器的可选后备解析器、宿主原生PDF阅读；纯图片再走真实视觉/OCR | 没有可读正文或可靠视觉时只降级对应字段 |
| 投档表是XLS而非XLSX | 使用原始XLS适配器及可选xlrd；XLSX使用openpyxl | 缺依赖时继续官方HTML/其他可读版本，不改扩展名假装XLSX |
| 某条原始官方来源失效 | 其他官方发布者或正式转载原文，再依信源规范检索独立B/C来源 | 未达门槛保持线索/观察，不提升为已核验结论 |
| 所有在线方式失效 | 消费已有认证材料，受影响任务记 `network_unavailable` | 不逐条反复调用同一个已证实失效的工具 |

每次网络动作仍只允许一次初始尝试和至多一次重试。一次浏览器启动失败并重试失败后，本轮停用该工具分支；转移到已有替代工具。相同故障在同一轮不按72个任务重复重试。只有URL、工具或网络条件发生实际变化才重新尝试，并记录变化。禁止绕过验证码、登录限制或反爬措施。

默认先用已有能力，不把配置收费API、重装浏览器或提供账号变成用户继续规划的前置条件。可选依赖遵守宿主已有授权范围；无权限安装时直接走其他分支和降级交付，不反复要求用户修环境。

下载仍经 `scripts.downloader` 的安全边界，保存原始字节、URL、时间与哈希。扩展名和HTTP Content-Type可能不一致；结合已打开官方原页和文件签名识别类型，不将任意返回内容当作附件。原始XLS不能通过改名、手抄CSV或另造XLSX伪装成已认证原文件。

PDF政策原文用 `pdf_text`，逐字段选择页码和精确引用；缺失字段省略。纯文本数字表仅在 `pdf_table` 能明确核对列头与行时使用，保留原始页/行位置及实际提取范围。复杂排版、错列、图片或遮挡不能强行标为 exact。宿主视觉提取必须实际看到原图/PDF，`ocr_rows` 不用于伪装人工猜测或未执行的OCR。

## 任务矩阵不等于全部必须成功

“18类×4年”等数量是有界查询矩阵。先处理各族最新年度；最新缺失才按 `Y → Y-1 → Y-2 → Y-3` 回查，不要求四年每项都找到资料。不同任务族可以继续各自进展；位次缺失不阻止专业政策、路径原文和准备行动。

每次 `next` 的 `research_summary` 显示真实完成、不可用和待处理数量。`older_year_resolution` 只列经过现有同族、年份、证据状态及coverage校验的旧任务收束建议；它本身不改变任务。核对可比性后，使用其中 `task_ids`、`newer_task` 和 `reason` 调用已有 `unavailable`。没有合格较新证据时继续回查，不能仅因较新任务有一条线索就跳过历史资料。

同一确定故障确实覆盖多个任务时，可在一次 `unavailable` 中重复传入对应 `--task`；其余任务继续。全局网络均不可用才可批量结束所有依赖在线材料的剩余任务，必须先保留已有材料。禁止用批量不可用掩盖尚未尝试的可用路径。

| 实际情况 | reason |
| --- | --- |
| 已确认当年资料尚未公布 | `current_year_not_published` |
| 来源检索完成但未达到采纳门槛 | `source_threshold_not_met` |
| 来源冲突不能解决 | `source_conflict` |
| 适用的网络读取方式均不可用 | `network_unavailable` |
| 对应格式无可用提取能力 | `capability_unavailable` |
| 存在门面验证通过的同族较新证据 | `newer_comparable_year_accepted`，必须同时传 `--newer-task` |

打不开网页不能证明资料未公布；缺PDF库不能证明该校不招生。以上reason记录工具或证据状态，不是学生资格结论。

## 零证据也走完诚实交付

所有任务分别 completed 或 unavailable 后，正常执行 `finish`。空证据包同样可以验证、保存并生成无数字的报告；这不等于假造“已认证结论”。`finish` 返回完整 `report_text`、实际 `sources`、`research_summary` 与 `delivery`：

- `profile_only`：没有采纳的公开事实。正文称“基于已确认画像的准备版”；位次、冲稳保、招生资格及报名日期保留不能判断/待核验。
- `partial`：有部分已认证事实及明确缺口。交付已成立的结论，逐项保留其余缺口，不把部分材料包装成完整认证。
- `evidence_supported`：按当前证据和计算结果解读；仍以每项实际状态为准，不表示录取承诺或全部资格已核实。

`pending=0` 只说明任务已经处理；不能据此说所有来源成功、所有资格已核实。`sources=[]` 应直接说明没有已采纳公开来源，不编造引用。若本地执行或报告工具本身完全不可用，直接在对话交付同样边界的准备建议，保留已确认画像和待核验事项，不伪称运行过计算或生成文件。

准备版也必须有用。按[对话结论写法](conversation-output.md)先说明能确认和暂不能确认什么，再根据用户已确认的年级、成绩口径、目标、外语和限制给出**明确标为准备建议**的行动、完成标准及复盘节点。这些建议可来自画像，不新增招生政策、数值估计或推荐学校，也不冒充引擎结论。

例如高一到2029高考：现在整理同口径成绩和年级位次、核对目标专业选科；下一次同口径大考后检查趋势；之后用实际校准材料重算定位；申请年度再复核当年计划、语种要求和公告日期。具体周期可作为建议提出，不能把2026公告日期当成2029截止日。已经回答的情况直接沿用，不再索要整套问卷。

把“补齐并复核路径政策”之类重复内部动作合并，逐条交代用户实际关心的路径及未知条件。核验工作由Agent继续承担，不要求家庭阅读内部JSON或承担72项技术任务。先交付可用内容，不以“你选修环境还是让我凭专业判断写”收尾。

## 不允许用免责声明替代依据

| 用户情境 | 必须保留的边界 |
| --- | --- |
| 高一月考600/750 | 校内成绩不是正式高考成绩；同满分不表示同难度。没有可信校排/联考锚点不能换算省排、前百分比或冲稳保 |
| 物理＋地理＋技术 | 保留三科，逐校逐专业核验；不能用“有物理”统称理工专业全开放 |
| 日语、英语基础弱 | 分别核对高考外语接受语种、校测语种、授课语言及后续能力要求，不能一刀切排除港澳/中外合作/综评 |
| 无竞赛或奖项 | 查具体项目申请类别与报名条件；不能把竞争优势缺失等同于没有报名资格 |
| 目标是几年后的高考 | 历史政策是当前参考基线，不是未来资格、分数线或截止日保证 |

第7题的 `scope` 由真实考试范围决定：校内月考/期中/校模考用 `school`；明确的省市联考分别用 `province_joint` / `city_joint`。`province_official` 只用于用户明确提供的正式省级高考成绩。来源盖章、“官方成绩”字样、750满分或让计算通过的需要都不能改变范围；不明情况保持待澄清，继续独立可做的内容。

“估算”“经验判断”“待核验”均不能授权凭空补数值、给学校打稳冲保标签或认定资格。已确认事实、认证证据结论、基于画像的准备建议、待核验项目应清楚区分，同时用自然中文讲完整。
