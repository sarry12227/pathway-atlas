# 学校／联考划线折算

用于第 7 主题收集考试信息，以及 `brief` 的 `exam_cutoffs` 分数定位。学校和联考划线、家长图片或文字均可用；它们是考试参照，不能冒充官方高考线。原始分、赋分及考试难度会影响可比性，满分相同本身不足以直接等同高考分。

## 逐轮收集

记录本次分数、考试名称、日期、范围与满分后，主动问一次：

> 这次考试，学校或联考有没有给出本科线、一本线等划线？有的话可以直接发图片，也可以把知道的分数告诉我，我们一项一项补齐。
>
> A. 有，可以发图片
> B. 有，用文字告诉你
> C. 没有／暂时不知道

这是一个问题。等家长回答后再问下一项；已有明确资料直接回填，不重复问。选 C 就记录暂无，继续第 8 主题，不要求家长去找表才能规划。选 A 时只有实际具备并成功使用读图／OCR 能力才算读到内容。选项无需强行显示在只能发送文字的宿主中；直接自然对话同样有效。

**能读图：**先读表头、科类和总分行，保留小数。只取学生对应的物理／历史方向；3+3 使用同一综合口径，不能擅自将图中的物理行作为所有 3+3 学生通用线。不要把各科划线相加，不把 `/`、空白或看不清的数当 0。用简短一句列出准备使用的两三条总分线，请家长确认或纠正；不复述整张各科矩阵。省份、考试身份、满分和计分口径优先复用已答信息，图片未写的不能靠猜。

**不能读图或读图失败：**明确说“当前环境读不了这张图片，您不用重新整理表格，我们用文字补两项就可以”。先只问“孩子对应方向的本科总分线是多少？”，回答后再问本次成绩附近的另一条线，例如“这张表的高优总分线是多少？”。每轮只问一个缺项；不一次索要六条线，更不索要 JSON、Excel、路径或安装 OCR。家长只知道一条也可继续。不清晰图片可请补说关键数字，不能声称已识别；家长无法补充时立即回退喜报估算，不重复尝试已不可用的工具。具备可用 OCR 时可由 Agent 自行使用，不把新工具安装变成用户前置任务。

拿到线值后，如果对应含义未知，再单独问“老师有没有说明这条线大致对应高考什么层次或分数？不知道也没关系”。老师已说清的不用再问；家长不知道就由 Agent 在既定研究预算内寻找本省参照。

## 对应与计算

先建立 `(本次考试线 x, 参照高考线 y)`，再计算学生分数 s：

- 本省、同科类、同一年参照高考口径下，优先采用能明确对应的本科／特控等线。“一本线”不能未经说明自动等同新高考特控线。“高优／双一流／超一流”没有全国统一官方分数，采用学校说明或本省代表层次资料建立对应，标为公开层次参照或家长转述老师参照。不能把湖北示例分数原样套到其他省。
- **相邻两点插值**：当 `x1 ≤ s ≤ x2` 时，`y = y1 + (s-x1) × (y2-y1)/(x2-x1)`。多条线时取夹住分数的相邻两条，保留计算小数。
- **线差法**：只有一对线，或成绩略超两点区间时，`y = y0 + (s-x0)`。区间外须注明“有限外推”；只在距最近线不超过满分 15% 时使用，超出则回退喜报等校准。这个范围是产品的粗估边界，不是统计规律。
- 必须对齐考试与高考参照的省份、科类、总分组成、满分和原始／赋分口径。满分不同、科目未学齐或计分不一致时不默认按总分比例缩放，也不直接应用等线差；保留资料并转用校排喜报方法。
- 插值默认给 ±10 分规划浮动；单点／区间外至少 ±20 分。Agent 可按考试覆盖和对应关系选 5–100 分的浮动并在 `basis` 解释依据。这些是敏感性假设，未经回测，不能声称精度提升了某个百分比，也不承诺未来自动提分。
- 得到分数中心及范围后，查**对应参照年、本省、同科类**一分一段。精确分数行取累计位次；小数分数或稀疏表可用相邻行插值并注明“省排插值，非官方精确同分位次”，不向表外外推。缺表仍交付已得分数，不能把整段定位清空。
- 已有喜报或校排出口时作交叉参照；分歧明显要说明哪个口径不同，必要时扩大参考范围，不机械取两种估算的平均数。无可用划线对应时用 `fallback_calibration` 继续喜报／校排路线。

## Agent 内部输入与续跑

原 20 题归一化接口不变。第 7 主题的划线追问是私有补充材料，**不把新字段硬塞进 `answers[7]` 或 v3 profile**。Agent 在私有工作区保留确认后的数字和口径，构造下面的 `calibration`，连同当前 `profile_digest` 放入 `brief` 输入。该输入与计算结果会由 `host_workflow brief` 一并保存；续跑读取保存的补充资料，不让家长重答，也不因旧画像没有划线字段报错。家长的私有图片／转述不要求公开 URL，不放进公开 `sources`，不写姓名、路径或图片中的其他个人信息。

字段（仅供 Agent 构造，家长不填写）：

| 字段 | 内容 |
| --- | --- |
| `method`, `basis` | `exam_cutoffs`；对应关系和规划浮动的简短依据 |
| `year` | 高考参照年，在当前四年参考窗口内，不是未来高考年 |
| `gaokao_province`, `gaokao_subject_group`, `gaokao_max_score`, `gaokao_score_basis` | 参照的省、组、满分、计分方式；组为物理／历史或 3+3 综合，与画像对应 |
| `exam` | `name,date,scope,province,subject_group,max_score,score_basis,source_kind,confirmed,lines`；日期和范围对应当前考试；`confirmed` 仅在家长确认后置 `true` |
| `exam.source_kind` | `parent_image` 实际读图并确认／`parent_text` 文字确认／`school_publication` 实际读取学校材料 |
| `exam.lines` | 最多 12 条 `{label,score}` 总分线，未知值为 `null`，保留小数；公开学校材料还提供每行 `citation`，家长材料无需伪造链接 |
| `anchors` | 最多 12 个 `{exam_label,gaokao_label,gaokao_score,reference_kind,basis,citation}`；`exam_label` 必须对应已收集线值。考试线和参照高考线必须同向递增，重复线值只选一个明确对应关系 |
| `anchors.reference_kind` | `official_cutoff` 官方控制线；`published_benchmark` 公开层次参照；`teacher_reported` 家长转述老师参照，最后一种以 `parent_statement` 代替 `citation`，明确未独立核验 |
| `margin_points` | 默认 10；单线／区间外至少 20。正文由程序披露浮动假设 |

公开的高考线及一分一段仍使用 [quick-planning](quick-planning.md) 中的 `sources/citation`。`score_table` 或 `historical_score_tables` 中选与 `year` 相同的一份表。`fallback_calibration` 是 `brief` 顶层的可选字段，允许已有 `school_report`、`school_rank` 或 `unavailable`；仅在划线不能得到分数时启用，不无限递归。

交付继续用固定七部分正文：**本次考试 XX 分 → 按 YYYY 年参照高考约 XX 分 → 省排约 XX 位**，紧接参考范围及一两句依据，再给普通批与多元路径。家长不看技术日志，不能只收到文件下载链接。
