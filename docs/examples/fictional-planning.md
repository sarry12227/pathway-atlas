# 完整输出样例：虚构数据，只看表达与结构

**这不是任何真实学生的评估。** 以下正文由当前程序实际读取仓库中的合成测试资料生成；学校名称、分数、位次、招生条件和示例链接均为虚构，不能作为真实选校或申请依据。尤其不能据此认定某个真实专业允许某种选科。

样例设定：高一、未来高考年份2029，本次600/750分、校排50/400，学校合成锚点为校排40对应省排40000、校排60对应省排60000。测试表中省排50000对应610分。浮动范围来自样例中显式设置的规划余量，既不是对未来成绩的预测，也不是录取概率。

生成入口是 `scripts.planning_brief.build_planning_brief`，资料基于 `tests.test_planning_brief.brief_fixture`，分别补充虚构路径培养信息。正文用来展示七部分结论、学校推荐理由、来源位置和现阶段行动；实际咨询必须使用该学生确认的信息和真实可读材料。

# 多元星途｜本次升学参考规划

## 一、成绩定位

本次考试：600/750分。
按2026年已公布高考口径作规划参考：**对应高考大致约610分，折合浙江省排约50000位**。
分数参考范围：590–630分；省排参考范围：40000–60000位。
估算依据：2026年学校出口锚点按校排插值；合成同校同口径校排出口；上下浮动20%为规划敏感性假设，非统计置信区间，不假定未来成绩自动提高。[2026年材料](https://policy.example/brief)
这是现阶段用于选校和安排准备的历史口径定位，不是对2029年实际高考结果的保证。
**怎样折算**：根据已读到的学校往年成绩与排名资料，估算这次校排大致对应的省排。参考分数再按注明年份、同一省份科类的一分一段表换算，未把本次校考分数直接当高考分。
