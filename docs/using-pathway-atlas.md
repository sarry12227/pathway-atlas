# 怎么回答、会得到什么，以及常见误解

无需把资料一次准备齐。说“请使用多元星途帮我做升学规划”，从当前最需要的一道题开始即可。下面是彼此独立的**虚构对话片段**，用于说明回答方式，不是真实学生案例，也不是让你照抄答案。

## 从第一句话开始

**AI：** 孩子在哪个省份参加高考？

**家长：** 湖北。

**AI：** 孩子现在读几年级？（单选）

- A. 高一
- B. 高二
- C. 高三
- D. 不确定

**家长：** 高二。

**AI：** 孩子预计哪一年参加高考？

每次只回答当前这一题就可以。也可以主动多说一点：“浙江、高一、物地技，最近月考600分。”AI会记下这些信息，接着问缺少的内容，不再从省份开始。说错了可以直接更正；不清楚就答“不确定”，不想回答可明确跳过。

## 学校有划线表时

**AI：** 这次考试学校或联考有没有公布划线？有的话可以直接发图片，也可以一条一条告诉我。

**家长：** 有，发了图片。

**AI（确实不能读清图片时）：** 孩子对应科类的本科线是多少分？

**家长：** 509.5分。

**AI：** 同一科类的高优线是多少分？

这里的数值只演示回答格式。AI会继续逐项核对考试和计分口径，再确认读到的线值。不能读图时不要求你安装识图软件或整理文件；没有划线也可以继续，由AI查找学校往年喜报等材料。

## 结果长什么样

完整正文依次给出：成绩定位、本省普通批冲3稳4保5、强基冲1稳1保1、综评冲1稳1保1、港澳冲1稳1保1、其他路径、现阶段行动。三类重点路径先列学校，再解释分数是否值得考虑、是什么和怎样培养，最后讲不适配点。每所学校说明专业匹配与主要限制，数字和政策带来源。

查看[完整输出样例](examples/fictional-planning.md)。这份样例由实际程序使用虚构测试资料生成，展示版式、解释和缺额处理；所有学校、分数、位次和链接均不能用于真实选校，程序真实执行不代表样例资料是真实招生数据。

真实咨询中，你会先看到类似这样的关系：

> 本次考试分数 → 依照已读材料折算的高考参考分数 → 对应年份省排 → 学校与路径安排。

随后用日常语言说明怎样算：两条可比划线之间看相对位置；只有一条划线时看分差；没有划线时，结合校排和学校往年喜报估算。省排数字越小，名次越靠前；“冲稳保”表示准备梯度，不能理解为录取概率或保证。

## 常见误解与正确处理

| 遇到的情况或想法 | 怎么理解、怎样继续 |
| --- | --- |
| “月考600分，就是高考600分” | 满分相同不等于难度相同。用可比划线或学校喜报进行校准，说明参考年份和浮动范围。 |
| “喜报是第三方文章或抖音发的，不能用” | 可读、能核对的分数段人数或上线率可用于注明出处和假设的估算；重复转载不能算多个独立证明，也不能直接认定学生报名资格。 |
| “划线表里各科线加起来就是总分线” | 分别划定的单科线通常不能这样相加。优先取孩子对应科类的总分线；小数照实保留，空白与斜杠不当成零。 |
| “用了湖北参考分数，就能给其他省直接套用” | 学校与路径的层次可参考，分数和位次必须按考生省份、科类及相应年份另行换算。 |
| “学校线够了，喜欢的所有专业都能上” | 还要看具体专业门槛与选科要求。浙江的‘技术’照实记录，不能替换成化学；有物理也不代表全部理工专业可报。 |
| “强基冲稳保三所就是一起报名” | 这是用于比较后择一的候选梯度，正式申报数量和限制以当年章程为准；普通批投档线也不能冒充强基或综评入围线。 |
| “日语、没有竞赛或英语薄弱，相关路径全部没戏” | 分项目核对报名语种、校测、培养和准备要求。预算够也不能替代语言要求，但不要凭单个标签排除整类路径。 |
| “没有精确位次，就应该等高三再规划” | 有依据时先估算；确实缺少个人校准时，仍给有材料支持的学校目标梯度和准备路径，明确哪些数字还没算出。 |
| “保档就是保录，缺学校就随便补满” | 保档仍有变动风险。符合条件的候选不足时写明缺额和原因，不重复学校、不用选科不符项目凑数。 |
| “某个网页打不开，就让家长选修环境还是继续” | AI先尝试已有替代方式，按时给可用内容；只有确实需要本人操作的权限问题才请求最少操作，不再要求选择是否开跑。 |

## 中断、更正或资料不全

- **继续之前的咨询：** 说“继续刚才的规划”。原记录还在时接着上一个未答项；已经确认资料则继续分析。不要因为更新技能再填整份问卷。
- **更正选科、预算或分数：** 直接说明变化。AI只确认受影响的内容，并重新计算相关结论；旧结果不会自动适用于新情况。
- **暂时不知道校排：** 明确说不知道。先收集其他信息；有可比划线就先估分，否则继续查学校资料并说明个人定位的缺口。
- **未来高考年份还没公布政策：** 先用已公布资料安排准备，注明年份；不能把今年报名日期当成未来年的截止日。
- **真正需要本人授权：** 只在当前平台完成所需操作，不把密码、验证码发到聊天里。完成后沿用原进度继续。
- **关心隐私：** 不必提供学生姓名、电话、详细住址或具体班级编号。完整高中校名有助于查喜报，结果匿名呈现；发成绩图片前可遮住姓名、学号等无关信息。

这些提示按需查阅，不是开始咨询前必须阅读或通过的一套检查。最终决定仍以申请年度官方招生要求为准。
